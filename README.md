# CAM L3 Marketing — Career ePortfolio

A responsive, single-page English-language ePortfolio designed for GitHub Pages.

## Before submitting
1. Replace all `[bracketed text]` with your real details.
2. Add your actual English and French CVs (PDFs are fine) and link them from the CV section if required.
3. Research three real role models using My Job Glasses, alumni interviews, or reliable professional sources. Add names, evidence, links and dates; do not claim interviews you did not conduct.
4. Find three specific international opportunities and add official links, eligibility, application dates and how each relates to a role model.
5. Record your personalised 2–3 minute English elevator pitch.
6. Check spelling, mobile layout, links and privacy before publishing.

## Publish on GitHub Pages
1. Sign in at https://github.com and create a **new public repository** named `cam-l3-eportfolio` (or another name).
2. Upload `index.html` and `README.md` to the repository root and commit the changes.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then click **Save**.
5. Wait for GitHub Pages to publish the site. Your site URL will usually be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Privacy
A public GitHub Pages website can be seen by anyone. Do not publish your home address, private phone number, student ID, or information you do not want public. Use a professional email if needed.
